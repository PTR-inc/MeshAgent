OpenSSL static library state
============================

Target version: openssl-1.1.1w (11 Sep 2023) - the last public 1.1.1 release.
  sha256: cf3098950cb4d853ad95c0841f1f9c6d3dc102dccfcacd521d93925208b76ac8
  Use ./fetch-openssl to download and verify the source tarball.

NOTE: 1.1.1 is end-of-life (11 Sep 2023) and receives no further public fixes.
1.1.1w is an interim step to close the CVEs published while 1.1.1 was still
supported. Migration to 3.5 LTS is tracked separately.

Configure flags are identical for every target (only the -O level and the
Configure target name differ); see the per-arch openssl-* scripts.

Anything at or below 1.1.1m is missing the fix for CVE-2022-0778 (infinite loop
in BN_mod_sqrt when parsing a crafted certificate), which the agent can reach
pre-authentication while parsing a server certificate. Prioritise those.


Rebuilding
----------
CI: .github/workflows/build-openssl-libs.yml (workflow_dispatch) builds the
targets reachable from GitHub runners and uploads them staged in this repo's
directory layout. It does NOT cover: arm2, armhf2, arm-linaro, pogo, poky,
poky64, linux-armada370-hf (vendor/Yocto toolchains), or the BSD targets.
Those still need a machine with the matching toolchain.

Manual: ./fetch-openssl, then run the matching openssl-<arch> script from
inside the extracted source directory.

GOTCHA: the makefile links the agent from $(OBJECTS) only - the static
libraries are not listed as prerequisites. Dropping in a new libcrypto.a will
NOT trigger a relink. Always `make clean` after updating these archives, or you
will silently keep testing the old OpenSSL.
